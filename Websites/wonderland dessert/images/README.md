Place your images here. The following images are referenced in the HTML files:

1. **logo.png** - Your Wonderland Desserts logo

3. **gingerbread-cake.png** - Gingerbread Cake product image

## Notes:
- Recommended size for product images: 200x200 pixels
- Recommended size for logo: 180px width
- Use PNG format with transparent background for best results
